# A Reel nobody gave a link for is not looked for

**Date:** 2026-10-11
**Status:** Accepted
**Decided by:** Furqaan
**Supersedes:** none

## Context
A creator says a Reel is posted by pasting its link. On YouTube, if the creator forgets, Cleared checks the channel itself when the go-ahead ends, because it already knows which video to look at. For a Reel it does not.

## Options
1. **Nothing is seen.** Without a link Cleared does not guess. The go-ahead ends as if nothing was posted, and the creator pastes the link.
2. **Cleared looks for it.** It lists the Reels posted since the go-ahead and takes the one whose length matches. It rescues a creator who forgets, but it can pick the wrong post and reads every recent Reel on the account.

## Decision
Option 1.

## Consequences
- When the money path asks whether a Reel was published, the answer is yes only if one is recorded.
- The link has to be given before the deadline. A Reel posted in time whose link comes after it is not paid: the hold is released at the deadline. The page must say so.
- William's line "if you forget to tap, we check" does not hold for a Reel.
