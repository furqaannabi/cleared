# Which live check finding gives which answer

**Date:** 2026-10-10
**Status:** Accepted
**Decided by:** Furqaan (William to agree)
**Supersedes:** none

## Context
The money path takes one of four answers from the live check and decides everything that follows: passed (the hold is captured), a failure the creator can fix (time to fix, then released), a failure that cannot be fixed (the brand has 48 hours to accept; silence releases), or cannot decide (the brand has 48 hours; silence pays). Which finding leads to which was not set. It decides when silence pays.

## Options
1. **Strict on the file, lenient on what YouTube will not say.** A wrong file or channel cannot be fixed. A missing link, code, hashtag or paid-promotion mark is fixable. A record YouTube does not return is "cannot decide".
2. **Anything Cleared cannot confirm is a failure.** Safest for the brand's money, but a creator can be blocked by something only YouTube controls.
3. **Only the file and the channel matter.** Fastest to pay, but it stops checking written and disclosure items the brand agreed to.

## Decision
Option 1. The worst finding wins.

## Consequences
- Cannot be fixed: the public video is not the approved file, or is not on the creator's connected channel.
- Fixable: a required link, code or hashtag is missing from the description; the video is not marked as a paid promotion; a written item is judged missing. The creator edits the post and checks again.
- Cannot decide: YouTube does not return the file's record or the paid-promotion mark; a written item's judgment is unsure.
- Passed: everything else.
- "Cannot decide" is never given for a fault Cleared saw. Silence pays only where Cleared could not look.
- A check that could not read YouTube at all gives no answer (see the record on lost access).
