# The unlisted video is given with the request for the go-ahead

**Date:** 2026-10-10
**Status:** Accepted
**Decided by:** Furqaan (William to agree, as his page gains a field)
**Supersedes:** none

## Context
An earlier record left the unlisted YouTube video to the publish step ([2026-10-09](2026-10-09-the-unlisted-video-is-asked-for-at-publish.md)) without saying when in it. A published video cannot be edited, so a live post that is not the approved file can only go to the brand to accept, or lose its hold. The match is a comparison of the file's size and length with YouTube's record of the upload, which can be read while the video is still unlisted.

## Options
1. **With the request for the go-ahead.** The creator pastes the unlisted video's link to ask. Cleared reads it and matches the file before anything is public. A wrong file is found while it can still be replaced.
2. **With "I've posted it".** Nothing new at the go-ahead, but a wrong file is found only once it is public.
3. **Cleared finds it itself.** Nothing to paste, but it uses more of YouTube's quota, two similar uploads could be confused, and the creator cannot see which was picked.

## Decision
Option 1.

## Consequences
- Asking for the go-ahead takes the video's link. With no accepted video there is no go-ahead, and nothing is asked of PayPal.
- The video must be on the creator's connected channel and be the approved draft's file: the same size, and the same length to within a second.
- A video that is already public is accepted too. The creator published before asking, at their own risk; what follows is the same.
- "I've posted it" sends no link. It asks Cleared to look at the recorded video.
- If YouTube does not return the file's record, the video is accepted on its channel alone and the live check cannot decide the match.
- William's go-ahead step gains a link field.
