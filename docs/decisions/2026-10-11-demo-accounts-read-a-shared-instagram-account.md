# Demo accounts read one real Instagram account the team owns

**Date:** 2026-10-11
**Status:** Accepted
**Decided by:** Furqaan (William to agree)
**Supersedes:** none

## Context
A demo account's Instagram is made up, so nothing can be read for it, and until Meta reviews the app only accounts the team adds as testers can connect. Demo accounts already read YouTube through one channel the team owns ([record](2026-10-10-demo-accounts-read-a-shared-channel.md)).

## Options
1. **A shared Instagram account.** One real professional account, connected once, holding the sample Reel. Every demo account reads through it, with the same code and rules.
2. **Demo deals are YouTube only.** Nothing to set up, but judges never see the Reel path run.

## Decision
Option 1.

## Consequences
- The team makes the account, switches it to professional, adds it as a tester, connects it once and names it in the settings.
- It holds the sample Reel, with a caption that meets the sample deal's written items. A demo deal with a Reel can only be finished with it.
- Its token has to be kept renewed, like any other.
